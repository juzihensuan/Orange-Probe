# Orange Probe v1.1.3 更新说明

v1.1.3 修复 Agent 更新任务反复下发、后台长期停留在“安装中”以及 Agent 多次上下线的问题。

## 更新状态机制

- 每次更新任务生成独立尝试 ID，同一任务只向 Agent 下发一次。
- Agent 会持久化安装中、成功或失败状态，服务端明确确认后才清除结果。
- Agent 重启期间如果更新器稍后写入结果，Agent 会在下一次上报前重新读取。
- 更新任务超过 5 分钟仍未确认时会显示失败和排查提示，不会自动反复重启 Agent。
- 正在更新或已经是最新版本的 Agent 无法重复点击更新。

## 测试 1.1.2 到 1.1.3

1. 先把服务端升级到 v1.1.3，Agent 保持 v1.1.2。
2. 登录后台并进入“系统更新”。
3. 对显示“可更新”的 Agent 点击更新。
4. 状态会从“等待 Agent”变为“等待重启确认”，Agent 更新时会短暂离线一次。
5. Agent 重新上线并上报 v1.1.3 后，状态应变为“更新完成”。

如果状态变为失败，请检查以下日志：

```text
Linux:   /var/lib/orange-probe-agent/<节点ID>/logs/
Windows: %ProgramData%\OrangeProbeAgent\<节点ID>\data\logs\
```

服务端和 Agent 更新不会清理节点配置、SLA、流量或监控历史。
